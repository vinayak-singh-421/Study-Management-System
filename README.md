# Study Management System

## Technologies
- HTML5, CSS3, JavaScript
- Python Flask
- SQLite
- Fetch API
- Werkzeug password hashing
- Flask sessions

## Run
```bash
python -m venv venv
venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

Application data is stored in SQLite (`database.db`). localStorage is not used as the primary data store.
