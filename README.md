## 📌 About The Project

**Study Management System** is a web-based student productivity and academic management application designed to help students organize their daily studies, academic information, tasks, subjects, attendance, marks, and skill development from a single platform.

The system provides a centralized dashboard where students can manage their study-related activities and monitor their academic progress.

---

## 🎯 Objectives

The main objectives of this project are:

- 📅 Organize weekly study schedules
- ✅ Manage academic and study tasks
- 📚 Manage subjects
- 🧠 Track DSA practice
- 💻 Track CSE skills
- ⏱️ Manage study time
- 📝 Maintain study notes
- 📊 Monitor attendance
- 🎯 Track marks and CGPA
- 📈 Analyze study progress
- 👤 Manage student profile
- 🔐 Provide user authentication

---

## ✨ Key Features

### 🏠 Dashboard
A centralized dashboard to view important study and academic information.

### 📅 Timetable / Weekly Schedule
Manage and view the weekly study schedule.

### ✅ Tasks
Create and manage study-related tasks.

### 📚 Subjects
Manage academic subjects and related information.

### 🧠 DSA Tracker
Track DSA practice and solved problems.

### 💻 CSE Skills
Maintain and track important Computer Science skills.

### ⏱️ Study Timer
Use a study timer to manage focused study sessions.

### 📝 Notes
Create and manage study notes.

### 📊 Attendance
Track subject-wise attendance and monitor academic attendance.

### 📈 Marks & CGPA
Manage marks and calculate/track academic performance.

### 📉 Analytics / Study Progress
View study progress and academic-related statistics.

### 👤 User Profile
Manage student profile information.

### 🔐 Authentication
The system includes:

- Login
- Register
- Logout
